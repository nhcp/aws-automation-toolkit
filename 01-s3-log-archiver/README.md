# ☁️ Project 01: S3 Automated Log Archiver

## 📋 Summary
High-volume system logs were threatening to exhaust disk space on production EC2 instances. This tool automates the lifecycle of these logs.

## 🛠️ Features
* **Compression:** 90% size reduction using Gzip.
* **Automation:** Automated offloading to AWS S3.
* **Security:** IAM Least Privilege configuration.

## 🚀 Impact
* **Reliability:** 0% disk-related downtime.
* **Cost:** 80% reduction in storage expenses.
