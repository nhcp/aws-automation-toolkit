# 🛠️ AWS Cloud-Native Automation Toolkit

## 📌 Overview
This repository contains a suite of production-ready Bash scripts designed to automate infrastructure management on AWS EC2. Each tool focuses on a specific pillar of DevOps: **Cost Optimization, Reliability, and Disaster Recovery.**

## 🚀 Projects Included
1. **[S3 Log Archiver](./01-s3-log-archiver):** Automated log rotation and cloud offloading.
2. **System Health Monitor:** Real-time vitals monitoring and automated responses.
3. **Disaster Recovery:** Automated retrieval of archives from S3 for data restoration.

## 🛠 Tech Stack
* **Cloud:** Amazon S3, IAM
* **OS:** Ubuntu/Linux (WSL2)
* **Automation:** Bash Scripting, Crontab
* **Tooling:** AWS CLI v2
